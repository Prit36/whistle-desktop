# Whistle Desktop v0.2.0

Import folders and multiple recordings into a queue, then transcribe them one at a time with the existing offline engine.

## Download and run

1. Download `Whistle-0.2.0-windows-x64.zip` and extract it.
2. Open `Whistle/Whistle.exe`.
3. Use **Open audio files**, **Import folder**, or drop recordings and folders onto the window. Enable **Include subfolders** to include nested audio.

The ZIP includes the model and native runtime. No internet connection, account, Python, FFmpeg, or additional model download is required to run it. Keep the `runtime` directory next to the executable.

## Changes

- Import folders, select several recordings, and process every dropped or command-line source. Files can be added while transcribing or recording.
- View queue progress and per-file results through the queue icon beside **Shortcuts**. A badge shows waiting files; hover for status.
- Pause/resume, skip the current file, remove waiting files, clear waiting/finished entries, and retry failed or cancelled files. Cancellation pauses remaining work; individual file errors preserve their diagnostics and continue to the next file.
- Discover audio in the background, deduplicate overlapping imports, and report unreadable paths and limits. The queue holds up to 1,000 entries; each discovery scans up to 100,000 folder entries. Links are skipped.
- Label batch transcript sections with filenames, suggest useful text-export names, and import folders with **Ctrl+Shift+O**.
- Keep source and recognition controls visible at 820 × 600. Queue paths and transcripts stay in memory for the session unless text is exported. Retrying appends a fresh attempt and preserves earlier partial text.

## Validation and limits

Formatting, strict Clippy, 31 ordinary tests, the native engine integration test, and the Windows x64 release build passed. Native window captures verify both supported layout sizes. A folder with two synthetic speech recordings and a deliberately damaged WAV exercises successful transcription and per-file error recovery. Synthetic fixtures are not a recognition-accuracy benchmark.

The downloadable binary targets **Windows x64** and is **unsigned**. Physical microphone capture, native OS picker interaction, and microphone permission behavior were not automated on the development host. Microphone text appears after a pause or a segment of up to six seconds plus inference time. Other operating systems require their own builds and validation.

See [VALIDATION.md](https://github.com/Prit36/whistle-desktop/blob/v0.2.0/VALIDATION.md) for test conditions and limitations. Verify the ZIP with the accompanying `SHA256SUMS.txt`. Dependency licenses and build provenance are included in the bundle.
