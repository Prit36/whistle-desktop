# Whistle Desktop v0.1.3

OGG/Opus voice notes now import offline, fixing the unsupported audio codec error.

## Download and run

1. Download `Whistle-0.1.3-windows-x64.zip` and extract it.
2. Open `Whistle/Whistle.exe` and import or drop your recording.

The ZIP includes the model, native runtime, and Opus decoder. No internet connection, account, Python, FFmpeg, or additional model download is required to run it. Keep the `runtime` directory next to the executable.

## Changes

- Added bundled Opus decoding for OGG voice notes and .opus files, including the file picker.
- Handle voice notes missing the OGG end-of-stream marker when their final page and packet are complete and the page checksum is valid. Cut-off pages, incomplete packets, and invalid final-page checksums still report errors.
- Added five Opus regression tests for mono/stereo audio, short clips, exact sample counts, cancellation, consumer errors, missing end markers, and damaged final pages.
- Includes the interface refinements since v0.1.1: more transcript space, clearer controls and status, processing and recording timers, smart transcript following, F6 editor focus, and keyboard navigation.

## Validation and limits

Formatting, strict Clippy, all 20 model-independent tests, the native engine integration test, and the Windows x64 release build passed. A real Opus voice note completed full local decoding and transcription. Synthetic tone fixtures check audio conversion and error handling; they are not a speech-recognition accuracy benchmark.

The downloadable binary targets **Windows x64** and is **unsigned**. Physical microphone capture and OS permission behavior remain unverified on the development host. Microphone text appears after a pause or a segment of up to six seconds plus inference time. Other operating systems require their own builds and validation.

See [VALIDATION.md](https://github.com/Prit36/whistle-desktop/blob/v0.1.3/VALIDATION.md) for test conditions and limitations. Verify the ZIP with the accompanying `SHA256SUMS.txt` before redistributing it. Dependency licenses and build provenance are included in the bundle.
