# Interface assets

`Phosphor.ttf` is the Regular icon font from [Phosphor Icons](https://github.com/phosphor-icons/web), pinned to `@phosphor-icons/web` version 2.1.2. It is embedded into the executable and uses a dedicated egui font family; no font or icon requests are made at runtime.

Source: https://cdn.jsdelivr.net/npm/@phosphor-icons/web@2.1.2/src/regular/Phosphor.ttf

License: MIT, included in `Phosphor-LICENSE.txt`. The packaging script includes this notice under `third-party/` in the portable bundle.

The interface uses the existing Fastframe Inter font setup for text. The approved visual foundation is recorded in `docs/design/refinement-reference.png`, with the original dark product screenshot in `docs/design/dark-reference.png`. Current screenshots and comparison evidence accompany `design-qa.md`.
