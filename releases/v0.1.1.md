# Whistle Desktop v0.1.1

A native Rust + Fastframe app for offline speech to text, powered by Whistle.

## Download and run

1. Download `Whistle-0.1.1-windows-x64.zip` and extract it.
2. Open `Whistle/Whistle.exe`.
3. Import an audio file or select **Use microphone**. Edit the transcript, copy it, or export text.

The ZIP includes the model and native runtime. Once extracted, no internet connection, account, Python installation or additional model download is required. Keep the `runtime` directory next to the executable.

## Included

- MP3, WAV, FLAC, OGG/Vorbis, M4A/AAC and AAC import.
- Pause-aware microphone transcription, language selection and keyword hints.
- Editable text, copy, atomic UTF-8 export and undo after clearing.
- Bounded audio buffers, a single native inference worker and event-driven rendering.
- Model/runtime provenance, dependency notices and SHA-256 checksums.

## Tested scope and limits

- The downloadable binary targets **Windows x64** and is **unsigned**.
- File transcription, audio conversion, segmentation, native integration, missing-device errors and UI rendering were checked. The development host has no attached microphone; real hardware capture and permission behavior remain unverified.
- Microphone text appears after a pause, or after a segment of up to six seconds plus inference time. This release does not provide word-by-word partial results.
- Whistle supports English, German, French, Spanish, Italian, Dutch and Polish. Accuracy depends on the audio; continuous speech can be split at a forced boundary.
- Other operating systems require their own builds and validation.

This release was built and verified locally, then published manually with GitHub CLI.

See [VALIDATION.md](https://github.com/Prit36/whistle-desktop/blob/v0.1.1/VALIDATION.md) for measured performance and exact test conditions. Verify the ZIP using the accompanying `SHA256SUMS.txt` before redistributing it.
